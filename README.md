# إسعافي: تطبيق الإسعافات الأولية المدرسي

تطبيق ويب تقدمي (PWA) عربي، يعمل بدون إنترنت بعد أول فتح. لا سيرفر ولا قاعدة بيانات ولا مكتبات من الإنترنت.

## هيكل المشروع

| المسار | المحتوى |
|---|---|
| `index.html` | الصفحة الوحيدة (زر الإسعاف 997 والتنبيه ثابتان في كل الشاشات) |
| `data/conditions.json` | **محتوى الحالات**. عدّله هنا مباشرة |
| `data/synonyms.json` | **مرادفات البحث** (عامية وفصحى). أضف كلمات لأي حالة |
| `data/triage.json` | **شجرة التقييم السريع** (أسئلة نعم/لا) |
| `js/` | الكود: `app.js` الموجّه والشاشات، `search.js` البحث، `triage.js` التقييم، `card.js` البطاقة الصحية، `qr.js` الباركود |
| `vendor/` | مكتبتا الباركود منسوختان محلياً: qrcode-generator (MIT) و jsQR (Apache-2.0) |
| `sw.js` | Service Worker يحفظ كل الملفات (cache-first) |

## بعد مراجعة الممرض/ة لحالة

1. عدّل النصوص في `data/conditions.json`.
2. غيّر `"reviewed": false` إلى `true` ليختفي وسم "مسودة تحتاج مراجعة ممرض/ة".
3. **غيّر رقم `VERSION` في `sw.js`** (مثلاً `isaafi-v1.0.1`)، وإلا يبقى الطلاب على النسخة القديمة.

> حالة الإغماء مكتوبة من النص المعتمد في وصف المشروع ولذلك `reviewed: true`. كل الحالات الأخرى وصفحة ضغطات الصدر مسودات.

إذا أضفت ملفاً جديداً فأضفه إلى قائمة `FILES` في `sw.js`.

## التشغيل محلياً

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`. الكاميرا ورمز PIN يحتاجان `localhost` أو `https`، ولا يعملان من `file://`.

## النشر المجاني

**GitHub Pages:** ارفع المجلد إلى مستودع، ثم Settings ← Pages ← Deploy from branch ← `main` / root.
**Cloudflare Pages:** Create project ← Direct upload ← ارفع المجلد (بدون أمر بناء).

كل المسارات نسبية، فيعمل التطبيق أيضاً تحت مسار فرعي مثل `username.github.io/isaafi/`.

## ملاحظات تقنية

- **البطاقة الصحية** محفوظة في `localStorage` على الجهاز فقط. رمز PIN محفوظ كتجزئة PBKDF2-SHA256 مع salt. الرمز **قفل للواجهة** وليس تشفيراً للبيانات نفسها.
- **باركود الإسعاف** نصه `FAE.z.<base64url>` ويحتوي البيانات المختصرة ووقت الإنشاء، مضغوطة بـ `deflate-raw`. ينتهي بعد ساعتين من الإنشاء. **باركود النسخة الاحتياطية** نصه `FAB.…` ولا ينتهي.
- **طلبات الشبكة:** بعد التثبيت تُخدم كل الملفات من الذاكرة. الطلب الوحيد الممكن هو فحص المتصفح التلقائي لملف `sw.js` بحثاً عن تحديث عند وجود إنترنت، وهذا ضروري لوصول تصحيحات المحتوى.
